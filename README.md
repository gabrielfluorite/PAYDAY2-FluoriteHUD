## **// Description**

**FluoriteHUD** was made with **solo stealth** in mind. Since some Payday 2 missions spawn new enemies and new civilians during the heist, this HUD is particularly useful because it allows you to **distinguish** how many enemies/civs are actually new spawns or not.

In **Art Galler**y for example, there's an inspector who appears after a few eliminations, and it's pretty helpful to **know when** he spawns and if he has **already left**.

In another example, **Bank Heist** can spawn new civilians walking down the streets and they can ruin your heist if you don't know they're there. With **FluoriteHUD**, when the new civs appear, you'll have an **indicator showing you that**.

In addition to the HUD informations, I also implemented a **civilian marking feature** to the stealth gameplay. This already exists in a form of a mod made by someone else, but in here, the feature is already **built-in** and includes a **pointing animation** when marking (similar to marking enemies, but with no sound). The basic **Chameleon** skill is required.

HUD colors are RGB customizable. Civilian marking can be enabled or disabled to your preference.

## **// Installation Instructions**

- Install **SuperBLT** separately (https://modworkshop.net/mod/58342).
- Extract the mod **.zip** into **PAYDAY 2\mods**.
- Confirm that the path **PAYDAY 2\mods\FluoriteHUD\mod.txt** is correct.
- Open PAYDAY 2 in **local single-player** and configure FluoriteHUD through the SuperBLT mod options menu.

## **// Main Features**

- **Six individual counters**: Initial Enemies, New Enemies (+), Cuffed Enemies, Initial Civilians, New Civilians (+) and Tied Civilians.
- Counting information disappears if the value is **zero**.
- **Civilian marking feature** in stealth with the regular interaction/mark key.

## **// Compatibility**

Mod only tested in **local single-player** missions and **no other mods** installed. Any other mod that changes the HUD in any way **will conflict** and cause issues with **FluoriteHUD**. Mod is **client-side only**.
